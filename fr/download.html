De l'installation au premier clip.

Quatre étapes, dont deux seulement te demandent quelque chose. Le reste, l'application le fait toute seule.

01

Lance l'installation

Lance le fichier d'installation et suis l'assistant — Jolnova s'ouvre à la fin.

  • Windows 10 ou 11, 64 bits
  • Installé pour ton propre compte utilisateur
02

La boîte à outils vidéo s'installe seule

Au premier démarrage, Jolnova télécharge FFmpeg, l'outil qu'il utilise pour découper et encoder la vidéo. Cela n'arrive qu'une fois et prend environ une minute sur une connexion normale.

  • Rien à chercher ni à configurer
03

Se connecter

Connecte-toi avec le compte créé sur le site. Ton abonnement est détecté automatiquement et tout se débloque.

  • Un compte est nécessaire — il est gratuit
04

Ajouter une source

Colle une chaîne Kick, Twitch ou TikTok — ou un lien YouTube, ou un de tes propres fichiers vidéo. Tes premiers clips arrivent dans En attente en quelques minutes.

  • Les clips attendent ton approbation

Windows va probablement t'avertir. Voici pourquoi.

Le fichier d'installation n'est pas encore signé, alors Microsoft Defender SmartScreen intervient au premier lancement. L'avertissement veut dire que Windows n'a pas vu ce fichier assez souvent pour le reconnaître — pas qu'il y a trouvé quelque chose.

✕

Windows a protégé votre ordinateur

Microsoft Defender SmartScreen a empêché le démarrage d'une application non reconnue. L'exécution de cette application peut mettre votre ordinateur en danger.

Informations complémentaires
Exécuter quand même Ne pas exécuter

C'est la fenêtre de Windows, pas la nôtre — le texte vient du système d'exploitation.

Comment passer outre

  1. Dans la fenêtre, choisis « Informations complémentaires ». Les deux boutons apparaissent en dessous.
  2. Choisis « Exécuter quand même ». L'installation se poursuit ensuite normalement.
  3. Windows retient ce fichier : l'avertissement ne réapparaît pas pour lui.
!

Nous préférons l'expliquer plutôt que le cacher. Nous avons demandé un certificat de signature de code : cet avertissement disparaîtra bientôt. D'ici là, chaque nouvelle version démarre comme non reconnue, quel que soit son contenu. Si vous préférez vérifier le fichier d'abord, téléchargez-le directement depuis la page GitHub Releases et analysez-le avant de l'exécuter.

CONFIGURATION REQUISE Ce dont il a besoin, et ce qu'il installe sur ta machine.

Configuration requise

Nécessaire pour le suivi en direct, la connexion et la rédaction des titres de clips.

Ce que fait l'installation

  • Installe l'application sur ta machine et ajoute une entrée au menu Démarrer.
  • Télécharge la boîte à outils vidéo une seule fois, au premier lancement.
  • Crée un dossier pour les enregistrements et les clips terminés — tu peux le déplacer dans les Réglages.
  • Laisse tes propres vidéos là où elles sont. Mes fichiers les lit sur place.
  • L'enregistrement, la détection des moments et les sous-titres restent sur ta machine. Seule l'étape qui rédige le titre en sort.

La désinstallation se fait comme pour tout programme Windows : Paramètres, puis Applications, puis Applications installées.

QUESTIONS SUR LE TÉLÉCHARGEMENT
Ai-je besoin d'un compte ?

Oui. Jolnova se connecte pour savoir quelle formule tu as, donc le premier écran après l'installation demande le compte que tu as créé ici. En créer un est gratuit et prend une minute.

L'essai est-il vraiment gratuit ?

Trois jours, ou cinquante clips approuvés — le premier des deux, et sans carte bancaire. Quand l'essai se termine, la production de nouveaux clips s'arrête, mais tout ce qui est déjà dans ta file et ta bibliothèque reste en place.

Pourquoi Windows dit-il que l'application n'est pas reconnue ?

Parce que le fichier d'installation n'est pas signé. SmartScreen avertit pour les fichiers qu'il n'a pas vus souvent, quel qu'en soit le contenu. Choisis « Informations complémentaires », puis « Exécuter quand même ».

D'où vient réellement le fichier ?

De notre page GitHub Releases. Le bouton ci-dessus pointe directement vers le fichier de la dernière version ; tu peux aussi ouvrir la page des versions toi-même, lire ce qui a changé et télécharger le fichier depuis GitHub.

Comment le mettre à jour plus tard ?

Retélécharge le fichier d'installation depuis cette page et lance-le. Le lien pointe toujours vers la dernière version, il n'y a donc aucun numéro de version à chercher.

Existe-t-il une version macOS ou Linux ?

Non. Jolnova est une application de bureau Windows et enregistre sur la machine où elle tourne.

Pas encore d'abonnement ? Commence par là.

Télécharge l'application, connecte-toi avec le même compte et ton abonnement s'active.
