FIRST RUN

Windows will probably warn you. Here is why.

The installer is not code-signed yet, so Microsoft Defender SmartScreen steps in the first time you run it. The warning means Windows has not seen this file often enough to recognise it — not that it found something in it.

✕

Windows protected your PC

Microsoft Defender SmartScreen prevented an unrecognised app from starting. Running this app might put your PC at risk.

More info
Run anyway Don't run

This is the Windows dialog, not ours — the wording comes from the operating system.

Getting past it

  1. Choose More info in the dialog. The two buttons appear underneath.
  2. Choose Run anyway. Setup then continues exactly as normal.
  3. Windows remembers this installer, so the warning does not come back for it.
!

We would rather explain this than hide it. We have applied for a code-signing certificate, so this warning will disappear soon. Until then every new release starts out unrecognised, whatever is inside it. If you would rather check the file first, download it straight from the GitHub Releases page and scan it before running.

None. Jolnova is a Windows application — there is no macOS or Linux build.

Room for recordings. A live stream takes roughly 5.6 GB an hour, and the cleanup budget that caps it is a setting you control.
Internet connection
Needed for live tracking, signing in and writing clip titles.
Jolnova account
Created free on this site. The app asks for it the first time it opens.
◫

What the installer does

  • Puts the application on your machine and adds a Start menu entry.
  • Fetches the video toolkit once, on first launch.
  • Creates a folder for recordings and finished clips — you can move it in Settings.
  • Leaves your own videos where they are. My Files reads them in place.
  • Keeps recording, moment detection and subtitles on your machine. Only the title-writing step leaves it.

Removing it is the same as any Windows program: Settings, then Apps, then Installed apps.

DOWNLOAD QUESTIONS

Before you run it

Do I need an account?

Yes. Jolnova signs in to see which plan you are on, so the first screen after installing asks for the account you created here. Creating one is free and takes a minute.

Is it really free to try?

Three days, or fifty approved clips — whichever comes first, and no card is asked for. When the trial ends new clip production stops, but everything already in your queue and library stays where it is.

Why does Windows say the app is unrecognised?

Because the installer is not code-signed. SmartScreen warns about files it has not seen many times before, whatever is inside them. Choose More info, then Run anyway.

Where does the file actually come from?

From our GitHub Releases page. The button above links straight to the newest release asset there, so you can also open the releases page yourself, read what changed and download the file from GitHub directly.

How do I update it later?

Download the installer from this page again and run it. The link always points at the latest release, so there is no version number to look up.

Is there a macOS or Linux version?

No. Jolnova is a Windows desktop application and records on the machine it runs on.
